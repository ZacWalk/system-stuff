# SysMate

A Windows system information and monitoring tool built with MFC (Visual C++ 6.0).

## Features

- **Process viewer** – enumerate running processes with search and tree navigation
- **Window viewer** – list top-level and child windows per process
- **Network viewer** – display active TCP/UDP connections (SNMP-based)
- **COM viewer** – show running OLE/COM objects
- **Performance monitor** – real-time CPU and memory graphs (supports NT and 9x)
- **Registry browser** – read and navigate the Windows registry
- **File version info** – display version resources for executables

## Building

Open `src/SysMate.dsw` in Visual C++ 6.0 (or later) and build the project.
